# OpenTypora v0.1.5 发布验证

日期：2026-10-06。平台：Windows x64。

本次发布包含跨文件正则搜索、大纲和字数统计的线程复用优化（`d2e134b`），并将中英文 README 的下载入口更新到 v0.1.5。性能对比和资源生命周期说明见[线程复用性能验证](线程复用性能验证.md)。

## 构建与回归

- `npm run build`：类型检查、Vite 生产构建、Electron 主进程与预加载构建通过。
- `npm test`：35 个测试文件通过，342 项通过，12 项原有跳过。
- `npm run test:analysis`：真实 Chromium 中的分析结果、源位置、线程复用、短文档切换和释放通过。
- `npm run test:multi-window`：启动队列、中文/空格/相对路径、多窗口独立编辑/保存/撤销、关闭后重启通过。
- `npm exec -- electron-builder --win nsis portable --x64 --publish never`：安装版和便携版构建通过。
- `npm run test:installer`：使用生产 NSIS 宏和当前打包文件，在隔离目录、隔离注册表验证安装、右键打开、卸载、默认编辑器与用户文档保留、实际安装后程序冒烟、新版本注册项保留，最终全部通过。
- 便携 EXE：入口参数转发通过；实际子程序与解包版 `app.asar` 的 SHA-256 相同；子程序、启动器退出码均为 0。
- 打包内容：核对 278 个构建文件，包含主进程、预加载、渲染资源与 LICENSE，全部与当前构建相同；包内版本为 0.1.5，搜索线程复用与分析响应协议均已包含。
- `latest.yml`：版本、安装包文件名、字节数、SHA-512 均与最终安装包相符。

测试窗口隐藏，用户数据和文档均与真实工作区数据隔离。

## 菜单冒烟检查的时序修正

发布准备过程中，固定 30 毫秒延时的隐藏窗口菜单检查曾在“段落 → 代码”失败；同一产物的独立复跑和安装流程复跑通过。为减少该检查对后台帧调度的依赖，本次关闭 `--smoke-test` 窗口的后台节流，等待字体就绪、菜单可见及连续两个采样的几何位置稳定，再执行原有的边界、侧向展开与键盘焦点断言。普通使用模式保留后台节流。

检查仍使用原来的 1264×861 与 720×480 两组窗口尺寸，每组验证 10 个二级菜单；等待有时限，没有放宽边界断言。越界错误增加窗口、父菜单、子菜单和触发项的坐标诊断。多窗口测试的隐藏窗口设置也同步适配。

增强检查时曾错误地比较“导出”按钮与“导出格式”菜单的无障碍名称，已纠正。上述调整后的最终便携版和安装版实际程序冒烟检查均通过。
