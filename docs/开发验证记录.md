## 本轮集成与显示修复（2026-10-03）

本轮已经在 Typora 1.12.4 与 OpenTypora 的实际 Windows 窗口中打开同一份 [扩展功能样例](fixtures/advanced-feature-sample.md)，两者缩放均为 100%。发现并落地修复了 YAML/Setext 误识别、标题字号、预览空白继承、替换装饰边界、目录排版、重复脚注尾注、警告框空白、图片居中、表格列布局、缺失图片显示，以及公式编号与 Physics 配置缓存问题。

逐项差异、修复和证据状态见 [Typora 显示对比与修复记录](Typora-显示对比与修复记录.md)。修复前的差异已经实际观察；本轮已用 Windows 窗口捕获完成修复后桌面复核；三类图表另用独立样例复核。

大纲也已与 `markdown.strict` 设置同步：宽松模式识别顶层无空格标题，正文位置保持原文 UTF-16 偏移；大文档 Worker 请求、缓存与迟到结果校验携带严格模式状态。对应专项测试已经执行，最终当前构建的完整检查数量由下表统一记录。
