## 五个内置主题的表格与块布局修复（2026-10-04）

通过 silence-computer-use 在独立 Windows 会话中打开 `docs/README.md`，实际复现 Newsprint 表头与表体分离。根因是基础预览样式将 `<table>` 改为 `display:block`，浏览器为表头和表体生成独立的匿名表格，分别计算列宽。预览块还继承了 CodeMirror 的 `white-space:break-spaces`，生成 HTML 的格式换行变成可见空行。Github 的专用样式覆盖了这两个属性，因而掩盖了共用结构问题。

在 Chromium 标准模式下，分别覆盖换行规则和表格 display：只改换行仍有列宽错位；恢复原生表格布局后列边界一致。原有编辑交互测试入口缺少 doctype，浏览器的怪异模式会重置表格换行继承，未能暴露此问题；本轮将编辑交互及新布局测试入口统一为生产应用使用的标准模式。

共用修复包括：原生表格网格、外层容器横向滚动、预览块正常 HTML 换行规则，以及行内代码显式保留空格。Github 移除独有的固定列宽布局，五个主题均根据单元格内容计算列宽。源码、代码块缩进、用户“保留空格”设置继续保持各自的原有语义。此次也消除了标题、段落、列表、引用与公式等预览块中由生成 HTML 换行导致的额外空行。
