# Typora 1.12.4 功能观察记录

调查日期：2026-10-02 · 平台：Windows x64 · 界面：简体中文 · 当前主题：Github

用途：给 OpenTypora 提供参考证据及命令覆盖清单。记录的是本机安装版本，不代表官网最新版本。未检查其他操作系统，也未测量性能。

## 1. 方法与证据边界

通过 computer-use 的窗口、鼠标和键盘接口操作；截图使用用户指定的 windows-window-capture。每次观察后删除临时截图。本记录不包含原文内容、最近文件路径或个人目录名。

原窗口有未保存标记。此次未改写其正文、未保存、未替换、未增删表格、未上传、未执行导出或修改偏好。源码/侧边栏/写作模式等可逆操作完成了实际观察；视图和滚动位置曾改变。新建窗口和打开独立样例没有获得可确认的结果，不能据此判断功能成功或认定参考软件缺陷。

证据：A=执行后确认结果；B=可见入口/配置；C=工作流未验证。开发需求中的 D=OpenTypora 产品决策，详见 [PRD](OpenTypora-产品需求文档.md)。菜单展开本身已观察，但其中命令仍记为B。设置“当前值”不是出厂默认值。
