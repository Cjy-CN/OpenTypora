# OpenTypora v0.1.6 发布验证

日期：2026-10-06。平台：Windows x64。

本次包含摘要列表裁切修复（`42b5ccd`）和已审阅的 A 方案整合（`ea11bed`）：目录工具按钮 32 px、SVG 图标 18 px、目录名称 14 px；状态栏 36 px、字号 12 px。新建与快速打开在文件和大纲面板中均可使用。列表行高同步适配增大的摘要字体，保留子目录路径，去掉同目录文件的重复文件名。中英文 README 下载链接更新为 v0.1.6。

## 本次实际验证

- `npm test`：35 个测试文件通过，343 项通过，12 项原有跳过。
- `npm run test:sidebar`：实际 Chromium 中通过 144 项布局检查，覆盖 6 个主题、中英界面、3 种侧栏宽度与滚动位置；检查文字行高、重复文件名、按钮尺寸、悬停提示和原文保持。
- `npm run build`：类型检查、Vite 生产构建、Electron 主进程与预加载构建通过。
- `npm exec -- electron-builder --win nsis portable --x64 --publish never`：安装版、便携版与更新元数据生成成功。
- `npm run test:installer`：在独立目录和注册表路径中使用生产安装宏验证实际安装后启动、Markdown 右键打开和打开方式、卸载程序、默认编辑器与用户文档保留，以及新版本注册项保留；全部通过。
- 便携 EXE：实际启动器转发 `--smoke-test` 参数、子程序与启动器退出码均为 0；实际启动的 `app.asar` 与当前打包内容 SHA-256 相同（`aabcfe8958bbb4d8475021f6696d1e43e5175adff907adb92cbf79e3c74dbda4`）。
- 安装后与便携实际程序的冒烟检查包括编辑器、桥接、Node 隔离、公式与图表渲染、源码往返、两种窗口尺寸下的二级菜单及目录导航。
- 打包内容：278 个构建文件均与当前构建相同，包内版本为 0.1.6。
- `latest.yml`：版本、安装包文件名、文件大小和 SHA-512 与最终安装包相符。

测试窗口隐藏，用户数据、文档及安装注册表均与实际工作环境隔离。原型页面和审阅截图已在整合完成后清理，不包含在发布产物中。
