# 工程基线与协作契约

基线日期：2026-10-02。范围仍为完整PRD；本文只规定并行开发的共同基础。

## 技术与边界

采用Electron桌面壳、React界面、TypeScript契约、Vite构建和CodeMirror编辑内核。Node.js 24作为开发环境，依赖精确解析记录在package-lock.json。Electron通过隔离的preload暴露有限DesktopBridge，渲染进程不直接访问文件系统或执行命令。

CodeMirror用于同一原始Markdown的编辑与即时排版，减少富文本序列化导致的原文改写。实现必须保留未知语法、不完整标记、空白和换行；图表/公式通过异步节点渲染接入。

来源：[Electron应用教程](https://www.electronjs.org/docs/latest/tutorial/tutorial-first-app)、[CodeMirror指南](https://codemirror.net/docs/guide/)、[Vite指南](https://vite.dev/guide/)。这些来源仅用于工程机制，产品事实仍以桌面观察记录为准。

## 共享接口

| 文件 | 契约 |
| --- | --- |
| `src/shared/contracts.ts` | 文档、选择范围、事务、文件结果、搜索、图片、导入导出、DesktopBridge和IPC方法白名单 |
| `src/core/document.ts` | 唯一正文、版本、选择、历史、保存快照结果；未编辑的视图操作不增加版本 |
| `src/core/commands.ts` | 命令定义、上下文、可用条件和执行结果；未注册执行器的命令不可用 |
| `src/shared/command-catalog.ts` | 全局稳定命令ID；菜单/快捷键/右键共用 |
| `src/shared/settings.ts` | 配置默认值、分类、类型校验、持久化值、生效时机 |
| `src/shared/components.ts` | 编辑器与工作区组件输入、编辑器命令/定位句柄 |

文本偏移按JavaScript UTF-16代码单元计算，CR/LF按真实原文分别占位。事务中的全部修改范围相对baseVersion，以从后向前应用替换避免位置漂移。历史恢复增加版本；保存结果记录其冻结版本，不能清除后来输入的脏状态。

命令执行器只有一个注册责任方，公共命令新增或重命名由主agent协调。所有异步任务检查文档ID、版本/节点标识和输入内容，旧任务不回写新文档。配置UI和高级配置使用同一Schema，非法值拒绝或迁移，不能只改变开关视觉。

## 文件归属与并行计划

共同基线验证并提交后再创建worktree。主agent留在当前目录，三个模块agent分别在独立worktree上开发独立分支。

| 所有者 | 可修改范围 | 集成责任 |
| --- | --- | --- |
| 主agent | `src/shared/`、`src/core/document.ts`、`src/core/commands.ts`、`src/App.tsx`、`src/main.tsx`、`src/styles.css`、`electron/main.ts`、`electron/preload.ts`、包/构建文件、根测试与报告 | 公共契约、命令装配、依赖、整体验证和合并 |
| Editor agent | `src/editor/`、`src/core/formatting.ts`及对应模块测试 | CodeMirror即时/源码、IME/历史、所有编辑/格式/段落/表格命令 |
| Services agent | `electron/services/`及其内部测试 | 文件/恢复/图片/上传/导入导出/系统服务，公开DesktopBridge实现 |
| Workspace agent | `src/ui/`及其内部测试 | 文件/大纲/搜索、设置、主题、模式和统计，WorkspaceShell组件 |

需要改公共接口时先报告具体变更和消费者，主agent统一提交；各模块再同步。所有者可以在本模块中增加文件，不在其他模块复制另一份正文模型或契约。主agent审查提交后合并，工作树保留到确认集成完成。

## 验证与状态

共同基线检查：类型、生产构建、文档事务、迟到保存、只读、配置校验、命令可用条件、UTF-8 BOM和外部冲突。桌面启动验证单独记录。共同基线的临时输入区域不是完整即时编辑器，未接入的服务会明确返回不可用；并行模块负责替换并实现完整产品能力。

完整交付仍依据172条验收用例，任何模块的构建通过都不能替代整体功能验收。
