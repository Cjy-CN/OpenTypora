# 菜单层级检查（2026-10-03）

本次针对菜单栏子菜单的展开位置、滚动和键盘交互进行检查。参考对象为当前机器已安装并打开的 Typora；以 Computer Use 读取菜单，并使用 windows-window-capture 查看可见窗口。此报告不代表全部产品验收或 Mermaid 类型矩阵已完成。

## 发现与修复

原“文件 → 导出”将18个导出配置平铺在文件菜单里。其余带路径的菜单组曾被平铺为标题和命令，临时改成 details 后仍然向下展开。现由统一的 WorkspaceMenu 生成菜单树，子菜单在独立面板中展开。

| 一级菜单 | 检查的二级菜单 | 结果 |
| --- | --- | --- |
| 文件 | 导出（18个配置） | 右侧独立展开，不增加文件菜单高度 |
| 编辑 | 选择、范围、文本、搜索 | 独立侧面展开 |
| 段落 | 表格、代码、公式、警告框 | 独立侧面展开 |
| 格式 | 图像 | 独立侧面展开 |
| 视图、主题、帮助 | 当前命令目录中没有子菜单路径 | 保留一级命令，无额外平铺子菜单 |

菜单路径逐层生成，保留命令目录顺序；未来三级路径也不会被拼成一级标题。导出项继续传递原来的完整配置对象，配置名称不因界面语言切换被改写。

## 交互与边界

- 悬停或点击父项展开；同层只保留一个子菜单。
- 右侧空间不足时改为左侧展开；上下位置限制在窗口内容区域内。
- 每个面板分别滚动，滚动父面板时关闭其子面板，避免脱离父项。
- 上下方向键、Home、End 只移动当前面板中的可用项；右方向键进入子菜单，左方向键或 Escape 返回父项。
- 点击外部关闭菜单；顶层悬停切换后点击不再立即把新菜单关掉。
- 未注册或不可用的命令保持禁用；没有导出配置时给出到偏好设置添加配置的提示。
