# OpenTypora

Windows Markdown desktop editor. Product scope follows the complete investigated Typora 1.12.4 feature set.

```powershell
npm ci
npm run dev
```

`npm run check` validates types, tests and production builds. `npm run package` produces a Windows portable application. Node.js 24 is the development baseline.

See [product documents](docs/README.md) and [engineering baseline](docs/工程基线与协作契约.md). The engineering baseline is infrastructure for the full implementation; it does not claim completion of the product acceptance suite.
